A FEW GOOD QUESTIONS

再多了解一点。

Flowcraft 是一个真实的产品吗？

这是一个虚构的自动化工具概念展示页，用来探索工作流的视觉表达和交互方式。页面风格参考 n8n，Flowcraft 与 n8n 没有官方关联。

点击“运行演示”会发生什么？

演示会在当前浏览器中按顺序点亮节点，并展示预设的执行结果。不会连接真实 AI 或外部服务，不会读取、发送或保存你的个人数据。

可以在手机上使用吗？

可以。小屏幕会使用纵向流程布局，模板筛选、运行演示和导航都可以直接触摸操作。

我可以修改这个网页吗？

可以。这是一个无需构建的静态网页，页面样式和交互都在 index.html 中。通过页脚的 GitHub 链接可以查看本项目源码。
